Planck Node Architecture

Data Layout and Tick Execution Pipeline
Substrate: True-FCC D3Q19 Integer Lattice Gas (meso3i.c)

1. Coordinate Stencil & Even-Parity Sub-Lattice

The substrate runs on a 3D Face-Centered Cubic (FCC) lattice mapped onto a regular cubic coordinate array. Only the even-parity sites exist as physical nodes:

Physical Site Condition: (x + y + z) % 2 == 0

Odd-parity coordinates (where (x + y + z) % 2 != 0) are non-sites and hold zero memory. Because of this parity geometry:

  • Face-diagonal neighbors: 12 channels with step size (±1, ±1, 0), (±1, 0, ±1), (0, ±1, ±1). Because (±1) + (±1) + 0 = 0 or ±2 (even), single-step hops always land on valid even-parity sites.
  • Axial neighbors: 6 channels with step size (±2, 0, 0), (0, ±2, 0), (0, 0, ±2). Axial steps use stride 2 so that hops never land on invalid odd coordinates.
  • Stacking: Classic 12-neighbor close-packed crystal structure with A-B-C-A-B-C plane stacking.

2. Single Planck Node Memory State (Registers)

Every active node carries exactly zero floating-point variables. All states are unsigned integers (quanta counts):

Register C Type / Buffer Channels Physical Role
Moving Mass uint8_t iA[INCH] 18 channels Moving quanta counts streaming along 12 face and 6 axial channels at link speed c = 1 hop/tick.
Scalar Rest uint8_t iA[18] 1 channel Direction vector (0,0,0). Stationary mass trapped at the node; collides or radiates on carrier transit.
Directional Rest uint8_t iRA[IMOV] 18 channels "Frozen flux" (IDREST=1). Friction-parked quanta store their arrival channel, locking angular momentum (Lz) into resting mass.
Bound Excitation uint8_t iE 1 scalar Planck's n oscillator state. Absorbed photons raise bound thermal energy at fixed mass; sheds back via Einstein A21 decay.
Massless Photons uint8_t iPA[IMOV] 18 channels Massless messenger particles. Hop at invariant c = 1 hop/tick, never collide with each other, can carry 4 frequency bins.
Transit Counter uint8_t iLT 1 scalar Counts consecutive ticks that moving mass transits this node. Used for latency gating (ILAT) to shield young matter.
Arrival Counter uint8_t iPT 1 scalar Temporal cadence detector: counts consecutive ticks carrying light wavefronts.
Edge Dwell Delay uint16_t iD[18][4] 18 × 4 stages Sub-light delay-line pipeline (DWELL=k). Produces effective velocity v_eff = c / k built from discrete waiting stages.
Core Register uint8_t iQ 1 scalar Bound soliton-like core mass register used in condensation and peristaltic expansion regimes.
Phase Offset uint8_t iPH 1 scalar Local clock phase offset (0..3) for staggered, per-node emission beats.
Density Snapshot uint32_t iR 1 scalar Pre-collision mass map snapshot. Ensures spatial routing and friction checks are strictly synchronous.

3. The Ordered Tick Execution Pipeline (7 Steps)

Every tick advances the universal state machine through seven deterministic phases inside void meso3i_tick(void):

Step 1: Edge Delivery (Sub-Light Delay Line)

If DWELL > 1, quanta waiting in stage 0 of the edge buffer arrive at their destination nodes and land in local channel buffers. All deeper delay stages shift down by one slot (j → j - 1).

Step 2: Synchronous Density Snapshot

Every node computes its total local mass: mass = moving_channels + scalar_rest + directional_rest. This is cached globally into iR[site] so subsequent routing and friction decisions see a completely synchronous snapshot of the lattice.

Step 3: Local Node Interactions (collide_node)

Executes locally at every site without cross-grid communication:

  • Transit Cadence: If moving mass is present, iLT++; if quiet, reset iLT = 0.
  • Carrier-Gated Boil-Off: Parked mass can re-emit into moving channels. When IFRICM < 0, emission requires a transiting carrier dwelling for at least ILAT ticks. If IDREST=1, quanta return to their original directional channel.
  • Thermal Spontaneous Decay: If excitation iE > 0, the node probabilistically sheds bound energy (iE--) and emits a free photon (Einstein A21 spontaneous emission).
  • Pair Capture (Breit-Wheeler / Winding): Opposing quanta meeting head-on {c, -c} probabilistically bind into rest mass, locking the collision axis in directional rest.
  • Pair-Group Collision Shuffle: Two moving quanta are picked. The engine computes their vector sum c_i + c_j, looks up the equal-sum momentum group from GPAIRS, and swaps them for another member pair. Mass and momentum are conserved exactly.

Step 4: Core Clock Emission & Overflow

If Q-mode is active, nodes on their local clock beat emit excess core mass into moving channels. Any core mass exceeding capacity migrates to the lowest-density neighbor (gradient conduction).

Step 5: Mass Streaming (Spatial Transport)

Quanta in moving channels attempt to advance along their channel vector c:

  • Rest Mass: Remains stationary at the current node (Δx = 0).
  • Transit Drag (Space-as-Friction): If the destination density iR[dest] >= IFRIC, arriving quanta shed momentum and park into rest mass (or thermalize into excitation iE).
  • Elastic Reflection (Wall Refusal): If destination density exceeds IREFL, the hop is refused, and the quantum reflects onto the opposite channel (c ⊕ 1) at the source node.
  • Free Flight: Otherwise, quanta land cleanly in channel c at the destination node.

Step 6: Massless Photon Streaming & Matter Coupling

Photons advance along directional channels (iPA → iPB):

  • Vacuum Flight: Photons never collide with each other; speed of light c = 1 hop/tick is invariant.
  • Pair Production: Converging or opposing photon beams in vacuum pair-produce rest mass (IPHOT >= 8).
  • Matter Coupling: Upon encountering parked mass, photons can stimulate emission (laser ablation), impart radiation pressure, or absorb into bound thermal excitation iE++.

Step 7: Double-Buffer Swap

Pointers swap (iA ↔ iB, iPA ↔ iPB, iRA ↔ iRB), and the global clock advances (ITICK++).
